怎么读这张图

进入内核
应用先经过 SocketCAN，再进入内核中的设备驱动。

DMA 消费 ≠ CAN 成功
MM2S RD 前进仅表示 FPGA 取走了主机的数据。

ACK ≠ 应用确认
过滤掉数据的正常节点仍可发 ACK。

TxDone ≠ 对端回了一帧
当前驱动根据设备的发送报告完成本地 echo；它不是对端应用回复。

完成不是由中断触发
此驱动使用 delayed_work 轮询 S2MM，间隔受内核调度影响。

依据当前 TOSUN M2044 驱动的经典 CAN 路径。FPGA 内部流水线、对端软件与失败场景为教学假设，不连接真实硬件。详见项目 README 与 SOURCE_MAP。
