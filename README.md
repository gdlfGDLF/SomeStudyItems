# 通信实验室

双击本目录中的 **通信实验室.html** 即可在浏览器离线运行。无需安装依赖或连接板卡。也可打开 `index.html`（须保留同目录的 JS/CSS 文件）。

## 建议实验顺序

1. **正常收发**：保留 ID `200`、数据 `DC 05`，点击播放。点帧字段跳转，点逐位按钮或拖动时间轴查看一位。前两字节按小端 uint16 解读为 1500，仅作应用数据示例。
2. **位时序**：160 MHz、500 kbit/s、80%，点击“计算一组参数”，再点“生成实验”。观察实际分频 16、每位 20 TQ、1 TQ=100 ns、每位 2 μs、采样在 1.6 μs。展开手动设置可自行实验。
3. **连续 0 与位填充**：观察填充位及它与原始数据的区别。浅棕色边框为填充位。
4. **没有接收节点**：ACK 槽仍为 1，发送端未获得确认；可改成只听模式比较。
5. **ACK 成功，但过滤掉**：接收过滤器拒绝消息，并不阻止正常接收节点确认有效帧。
6. **数据位受干扰**：查看翻转位以及接收端 CRC / 填充检查结果。
7. **信号晚于采样点**：比较相对边沿迟到标记和采样位置。此滑杆不是线路单程传播时间。
8. **两个节点同时发送**：比较 0x130 和 0x120 的 ID 位，观察首个差异位上的退出。上方显示获胜节点的帧；两者使用相同负载。
9. **UART**：对照低位先发、起始位、停止位与可选奇偶校验；选择接收波特率不匹配，观察采样漂移。

修改配置后点击“生成实验”应用；点击播放也会应用修改。右侧接收结果是完整实验的最终预测，不随逐位回放隐藏。导出功能将当前已应用的配置、线上位、采样、结果和模型限制保存为 JSON。

## 范围与准确性

- 经典 CAN：11 位标准数据帧、0–8 字节。真实计算 CRC-15（0x4599）、SOF 至 CRC 序列的动态填充，独立接收去填充、格式与 CRC 检查。SOF 至 EOF 为 44+8N+填充位；显示总长度另含 3 位帧间隔。
- 电压是高速 CAN 典型示意：显性 H≈3.5 V、L≈1.5 V；隐性两线≈2.5 V。不是电路求解或示波器实测。
- 位时序使用实际分频和时间段数量，非寄存器编码。参数范围为实验范围；不保证特定芯片支持。目标值与实际值可能不同，以右侧实际位速率和采样点为准。
- 相对边沿迟到达到采样点时，模型保守报告时序不足。固定整帧传播延迟可被起始同步整体吸收，不能直接据本模型推导线长。完整重同步、SJW、时钟漂移及仲裁往返延迟尚未模拟。
- CAN 位翻转是接收解码实验，名义帧尾保留以观察检查结果。真实节点可能因位监测更早发出错误标志。本程序不展开错误帧、自动重发、错误计数或 Bus Off。
- ACK 仅代表至少一个节点在协议层确认，并非指定设备的应用已处理。
- UART：1–32 字节，8N1 / 8E1 / 8O1，3.3 V 逻辑示意。假定接收器能逐字节重新捕获起始沿，采用理想中心采样；严重失配下实际 UART 可能漏掉后续起始位。无校验时，错误数据可能被硬件静默接受，界面区分这种情况。
- 本工具没有板卡收发、CAN FD、CAN XL、SPI、I²C 功能。

## 修改与验证

源文件：`index.html`、`style.css`、`app.js`、`engine.js`。用 Node.js 执行：

```text
node engine.test.cjs
node build.cjs
```

`build.cjs` 生成所有资源内嵌的 `通信实验室.html`。`ui.test.cjs` 是开发用浏览器交互检查，需要 Playwright；通过环境变量 `PLAYWRIGHT_MODULE` 指定模块路径。
