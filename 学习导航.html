EMBEDDED LEARNING / 面向 PS 软件开发

从线上一个比特，
走到系统里一个任务。

四个离线实验入口。无需板卡，按自己的进度单步观察，再用真实硬件验证。

01 / 信号与帧

通信实验室

CAN 仲裁、位填充、CRC、采样，以及 UART 位流。

 02 / 数据走过的路径

总线实验室

CAN / FD / XL 九种帧格式与字段长度；SPI、I²C、UART，从软件提交到本地完成。

 03 / 从开机到通信

嵌入式系统实验室

启动、U-Boot、设备树和驱动；配有真实 Linux 串口与 UDP 示例。

 04 / 新增 · 控制与调度

RTOS 与寄存器实验室

RW / RO / W1C、中断清源、任务阻塞、优先级反转与周期漂移。
学习建议：先理解寄存器与中断，再比较 RTOS 等待方式和调度。后续可扩展 DMA / Cache 与 Zynq PS/PL；这些后续模块尚未实现。各实验是明确简化的教学模型，不替代芯片手册或硬件验证。
